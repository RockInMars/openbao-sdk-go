# OpenBao Go SDK Implementation Plan / 实现任务计划

> **For agentic workers:** REQUIRED SUB-SKILL: 执行时按环境采用 superpowers:executing-plans，或具备子代理时采用 superpowers:subagent-driven-development，逐任务完成测试与评审。

**Goal:** 实现可跨项目发布的 OpenBao Go SDK，并以有限范围的真实集成测试证明其行为。

**Architecture:** 独立 Go Module；根包公开客户端门面，叶子包承载 DTO/秘密类型；官方 api/v2 作为底层通信，统一执行器控制凭据、预算、错误与重试；业务流程留在调用项目。

**Tech Stack:** Go、OpenBao api/v2、标准库 net/http/crypto/x509/encoding/json、httptest、临时 OpenBao 集成环境。

**Spec:** `01-总体设计.md`；完整公开签名见 `02-接口契约.md`；验收编号见 `04-验收矩阵.md`。

## Global Constraints

- SDK module path 和工具链在 OB-001 固定；候选官方依赖 v2.7.0，不能称为已验证的现网版本。
- 不依赖 Gin/Fiber/Gorm/Redis/EMQX/saas-go 领域包；不创建业务表。
- 官方 MaxRetries=0，默认禁止双层重定向与环境配置读取；SAFE_READ 最多 3 次尝试，所有写/crypto/auth 动作默认单次。
- 普通操作总预算 10 秒，Issue/SignCSR 30 秒，登录 10 秒，续期 5 秒，拨号/TLS 各 5 秒。
- HTTPS 且验证证书；零 Namespace 模式无效；不 fallback root/latest。
- 明确 PKI 私钥不自动保管；KV 数据/操作标识同写；版本引用缺失不得伪造成功。
- 原始 Token、SecretID、私钥、秘密 body 不进入日志/Tracing/错误或测试报告。
- 本次计划所有实施项初始状态 NOT_STARTED；生成文档不是执行测试或接入现网。
- 仅临时 local/dev/test 环境；涉及 production/prod/staging、真实资金或真实凭据的步骤记录阻塞并继续独立任务。
