## 三、一次核对必要输入与凭据

先从用户明确确认的材料和现有非敏感配置查明下列输入；缺项集中询问，禁止要求用户再次发送明文 Token：

1. 服务环境性质，准确 HTTPS 入口，私有 CA/mTLS 等条件。
2. namespace 为 root 还是具体命名空间，不根据路径或 Token 猜测。
3. `BAO_REMOTE_TOKEN` 是否已经通过受控方式注入；只报告存在/缺失。
4. 已知存在的非敏感 KV v2 mount、测试 path、准确 version 和可核对的测试标记。
5. 若执行写入：已有测试 mount、独占前缀，以及创建、更新、软删除、恢复和最终回收各动作的授权范围。
6. 可选 PKI 测试角色/允许域名/TTL/信任根，以及 Transit 专用测试 key、类型和允许操作。
7. 权限负例所需的受限测试身份与明确的禁止访问测试路径。单一高权限 Token 不足以证明隔离边界。

环境或资源信息缺失只阻塞依赖它的动作；继续入口开发、本地负向测试、脱敏和报告验证。PKI/Transit 缺配置不阻塞已获准的 KV 测试。

## 四、实现独立入口并先完成本地回归

复用 `command_runner`、`RunRecord`、不可变 run_id 和现有 SDK 工厂。默认只读；隔离写入模式需要明确资源与回收配置，不能仅因 Token 有权限就自动启用。通用记录对象不得隐式启动 Go，Go 检查显式探测工具版本。

使用独立 `BAO_REMOTE_*` 输入，不使用 fixture 的 `BAO_TEST_ADDRESS` / `BAO_TEST_TOKEN`。不得修改 `integration_lock` 对外部服务器的拒绝行为，不将外部服务伪装成自有临时实例。

请求和返回值必须在持久化前过滤。禁止 HTTP dump、`curl -v`、完整 lookup-self 响应、完整错误对象或环境变量全集。只输出有限字段、用例名、SDK 错误码、状态和耗时；不输出 Token/accessor、KV 内容、请求正文或私钥。Observer 标签有限，回调快速，不额外访问服务。

## 五、冻结后依次执行获准远端检查

完成入口和本地回归后冻结 source_identity，再依照测试方案运行。每个阶段核实真实执行目标与收据，不只看退出码。

1. **TLS 与健康**：校验证书链、主机名和有效期；SDK ClusterHealth 不携带 Token/namespace。按实际健康状态决定能否继续，不能将健康成功当成凭据有效或业务可读。
2. **身份与精确路径能力**：在确认的 namespace 内查询自身身份必要信息及拟用路径的 capabilities。控制输出字段与请求数；自查接口被禁不能直接认定 Token 无效。认证请求可能消耗 Token 使用次数并产生审计记录。
3. **SDK 只读冒烟**：使用 StaticToken Provider，运行生命周期、指定版本 ReadVersion、CheckReady 和 Close；核对测试标记但不输出内容。缺已知测试资源时，不枚举业务目录寻找替代。
4. **KV 隔离读写**：仅在已批准独占前缀内创建本轮路径，CAS=0 防覆盖，验证指定版本读取、CAS 更新和旧 CAS 冲突；仅在许可内执行自有版本软删/恢复与最终清理。发现既有数据不得覆盖。
5. **权限负例**：只使用事先提供的受限测试身份和明确测试路径；不能把 404 单独当成隔离成功，不自行创建受限 Token。
6. **Transit，可选**：先确认专用测试 key 已存在，按其类型测试 encrypt/decrypt 或 sign/verify 与篡改负例；不触发隐式建 key、轮换、导出或删除。
7. **PKI，可选**：优先本地生成临时私钥/CSR，只调用专用角色及获准域名/TTL；验证证书链、SAN、用途和有效期。Issue、吊销分别需要对应范围，签发记录不会因删除本地文件而撤销。
8. **回收**：严格依据本轮资源清单和授权核对 mount/path/version/归属，只回收自己创建的资源；无法确认归属时停止相关删除并记录待处理项。

采用方案预算：只读串行、最多 10 个 API 请求/90 秒；隔离功能最多 60 个请求/10 分钟、并发最多 2。连接/TLS 约 3 秒、普通请求约 5 秒，PKI 使用既有适用预算。预检、查询、验证和清理都纳入预算，开始写入前预留清理额度；达到上限不得自动扩容或重试。

测试配置读重试为 1。写入超时或响应丢失记 UNKNOWN，不补发原写入；只能在剩余预算内独立读取确切自有路径核实。远端不进行 fuzz、压测、断网/响应截断、封印或故障切换；这些语义保留在可控本地测试/独立 fixture 中验证。

持续 5xx/限流、TLS/地址异常、发现既有数据、归属不明、清理不完整或输出疑似含凭据时，停止受影响远端动作。不得通过提权、关闭验证或修改服务器来恢复测试。
